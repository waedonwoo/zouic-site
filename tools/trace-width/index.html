PCB 走线线宽与载流计算器

给电流、允许温升、铜箔厚度和层位，反推 IPC-2221 图表拟合式下的最小线宽，并把这段走线的电阻、压降、发热一起算出来。纯前端计算，输入不上传。

你选了内层：内层热量被介质包住、只能沿铜箔横向传导，拟合式把系数 k 减半，所以同样电流要的截面积明显大于外层。这是模型本身的假设，不是某块板的实测。
算出的线宽低于 8 mil（约 0.2 mm）：这条曲线在小截面积区间本来就偏乐观（IPC-2152 的实测数据比 IPC-2221 那张图更保守），而板厂最小线宽、阻抗要求与工程习惯通常已经把宽度顶到 10–15 mil。这里的结果当「温升不是瓶颈」看，别当设计值。
长度填了 0：电阻、压降、发热三项无意义，结果按 0 给出；温升模型不看长度，线宽结论不受影响。
温升填了 0 或负数：拟合式在 ΔT=0 处的载流量是 0，反推不出截面积，所以结果留空。把允许温升改成 1 °C 以上。
电流填了 0 或负数：没有电流就没有温升约束，结果留空。这条模型只处理稳态直流。

这个数是怎么来的

I = k · ΔT^0.44 · A^0.725 A = w · t t = oz × 1.378 mil
  • I：稳态直流电流（A）
  • ΔT：允许温升（°C，相对室温）
  • A：走线截面积（mil²）
  • k：0.048（外层）/ 0.024（内层）
  • t：铜箔厚度，1 oz = 1.378 mil = 35 µm

拟合式来自 IPC-2221 载流能力图的公开复现，不是标准正文；常量与阈值全部列在下方，欢迎核对。

常量：k=0.048（外层）/ 0.024（内层）· b=0.44 · c=0.725 · 1 oz=1.378 mil=35 µm · 1 mil=0.0254 mm=25.4 µm · ρ(Cu, 20 °C)=0.0172 Ω·mm²/m

这个结果不能用来判断什么

这是稳态直流下的温升下限，不含阻抗与差分对要求、不含脉冲与电机启动这类短时大电流、不含阻焊开窗带来的载流增益、也不含铜箔批次与实际板厚偏差。量产前的关键网络请回 IPC-2152 原版图表、热仿真或实板温升测试。

常见问题

这里用的公式是哪个？

用的是 IPC-2221 载流能力图的常用拟合式 I = k·ΔT^0.44·A^0.725：外层 k=0.048、内层 k=0.024，截面积 A 用 mil²。它复现的是标准里那张图的走势，属于经验拟合式，不是标准正文，也不构成对某块板的一致性认证。

算出来的线宽可以直接用吗？

只能当「不低于多少」的下限用。它只约束温升，不处理阻抗控制、差分对间距、高密度布线下的相邻散热、脉冲电流与浪涌；这些要另做仿真或实测。

为什么内层要宽那么多？

拟合式把内层的 k 取成外层的一半：内层被介质包住，热量主要沿铜箔横向传导，散不出去。同样电流与温升下，所需截面积约为外层的 2.6 倍（因为指数 0.725，系数差 2 倍会变成 2^(1/0.725) ≈ 2.62 倍）。

走线长度会影响线宽结论吗？

不会。温升模型只看截面积和散热条件，长度只决定电阻、压降和总发热量；所以页面把「长度」单独放在一个输入里，只用于电阻那几行。

我要走的是脉冲电流（比如舵机堵转）怎么办？

这个模型是稳态直流假设，脉冲负载请按占空比与热时间常数另算，或直接用实板温升测试。页面不会替你猜一个脉冲降额系数——那需要一个具体的波形才成立，凭空写就是编数字。

为什么 0.5 A 只算出几 mil 宽？这个能用吗？

公式在小截面积区间本来就偏乐观：IPC-2221 那张图是把大块铜箔的实测趋势拟合出来的，IPC-2152 后续的实测数据显示窄走线的实际载流能力低于它。本站只做原式复现、不做这层修正，所以页面在小电流时仍算得出一个很小的宽度——但板厂最小线宽、阻抗要求和你自己的工程习惯都会把它顶到 10–15 mil，算出的宽度小于 8 mil 时页面会明确提示。
