内核、引导与构建

Kernel / Bootloader / Buildroot / Distro

从内核源码到根文件系统的主干工具链。做 BSP、裁剪系统、定位启动失败时，这几处是一手信息源，比二手教程可靠。

Linux 内核官网

www.kernel.org
内核各分支（mainline / stable / longterm）的官方发布点，提供 tarball、changelog 与 git 仓库地址。动手移植前先在这里确认目标版本是否仍在长期维护。
可直达 Linux 内核

Linux 源码在线交叉索引

elixir.bootlin.com
按版本、符号、文件三种维度检索内核源码，函数调用与结构体定义可一键跳转。读驱动时比在本地 grep 更快建立调用链。
脚本受限 源码阅读 驱动
有机器人校验，浏览器正常打开

U-Boot 源码下载

ftp.denx.de
DENX 维护的官方发布目录，按版本号排列 tar.bz2 与校验文件。板级移植时跟随 SoC 厂商 BSP 指定的版本，不要直接拿最新版。
可直达 Bootloader 移植

Buildroot 源码

buildroot.org
各年度版本的源码包与 changelog。用它拉出交叉工具链和根文件系统，产物比 Yocto 轻，适合中小规模产品；定制深度要求高时再考虑 Yocto。
可直达 构建系统 根文件系统

Debian 官网

www.debian.org
稳定版与测试版的官方镜像入口，含 arm64 / armhf 的 netinst 安装器。需要长期稳定运行的设备端或基础镜像常从这里取。
可直达 发行版

Ubuntu 官网

ubuntu.com
LTS 与过渡版本的发布页，服务器版、桌面版、云镜像分开提供。树莓派等 ARM 板卡另有专门镜像页，选型时注意 LTS 支持窗口。
可直达 发行版

GNU 项目官网

www.gnu.org
GCC、glibc、binutils、GDB、make 等基础工具的总入口，各项目手册与邮件列表在此索引。遇到工具链行为差异，查官方手册最准。
可直达 工具链

MicroPython 官方

micropython.org
官方固件下载与文档中心，按芯片端口分类，quickref 页列出各板可用模块。原清单指向的中文站已停更，以官方文档与 docs.micropython.org 为准。
入口已变更 MicroPython 固件
原中文站 micropython.openioe.net 已无法解析

开发板厂商资料中心

Vendor Docs & Examples

国产开发板的资料大多由厂商自行分发，官方文档站的版本比网盘包新、比论坛帖全。拿到板子先按型号在这几处对齐 BSP 版本。

百问网资料下载中心

download.100ask.net
韦东山团队的配套资料站，按课程与板卡（i.MX6ULL、STM32MP157、T113 等）归档源码、工具链与文档。跟课程学时按章节取对应资料包最省事。
可直达 i.MX6ULL STM32MP1

野火资料下载中心

doc.embedfire.com
野火（EmbedFire）在线文档站，按板卡型号组织教程、例程与外设手册，可直接全文检索。比整包下载更容易定位到某一章的例程。
可直达 STM32 Linux

正点原子资料下载中心

www.openedv.com
按 STM32 / i.MX6ULL / FPGA / Linux 分卷的资料总目录，含原理图、例程与视频配套文档。下载前核对板卡版本号，避免资料与硬件不符。
可直达 STM32 FPGA

迅为电子官网

www.topeetboard.com
北京迅为（iTOP 系列）官网，产品页给出核心板规格、底板接口与 BSP 版本说明。做 i.MX6 / Exynos / RK 平台选型时可对比核心板尺寸与引脚定义。
可直达 i.MX6 核心板

小熊派实验例程

gitee.com
小熊派（BearPi）的例程仓库，覆盖 LiteOS、OpenHarmony 与常见外设驱动，每个目录都是能直接跑的最小工程。适合照着改第一版 bring-up 代码。
可直达 OpenHarmony LiteOS

荔枝派 Zero 指南

www.kancloud.cn
全志 V3s 平台的荔枝派 Zero 上手文档，从烧录、串口登录到主线内核编译都有分步记录。V3s 主线性好、成本低，是入门 Linux 板常选方案。
可直达 全志 V3s 主线内核

电堂科技

面向 STM32 的中文教学站，内容偏外设实验与工程实践，配可下载的工程模板。从标准库转到 HAL 阶段、查具体外设配置时用得上。
可直达 STM32 外设

中文社区与论坛

Forums & Community

关于这份清单

  • 入口以 2026-10-29 的实测结果为准，标注了四种状态：可直达（直连 200）、 脚本受限（存在但拒绝自动化请求，浏览器可开）、入口已变更 （原链接失效，已替换为仍可用的地址）。
  • 失效的入口不做静默删除：「地瓜派 digoboy」在被收录时已跳转至无关的登录页，暂不提供链接； 「easyicon」「code.py40.com」「cpp.hotexamples.com」「micropython.openioe.net」均已下线， 分别以 iconfont、PythonGUIs / zetcode、hotexamples 主站、MicroPython 官方站替代，并在卡片上注明。
  • 同一站点有多个入口的（例如野火的文档站与论坛、迅为的官网与社区）分开收录，因为用途不同。
  • 如果你发现某个入口打不开了，可以在贡献指南里反馈，核对后会更新这一页。
