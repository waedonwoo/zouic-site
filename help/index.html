帮助中心

欢迎来到 ZouIC 帮助中心。在这里您可以找到使用平台的详细指南和常见问题解答。

快速入门

1. 浏览开发板

访问开源开发板页面，浏览我们收录的 67 款开发板。您可以按厂商、芯片架构进行筛选，找到适合您项目需求的开发板。

2. 查找项目

访问项目列表页面，浏览 1513 个开源项目。您可以按开发框架、难度等级进行筛选，找到适合您技能水平的项目。

3. 使用搜索

使用页面顶部的搜索框，输入关键词快速定位开发板和项目。支持按类型筛选，只搜索开发板或项目。

4. 注册账号

注册账号后，您可以收藏喜欢的项目、发表评论、参与社区讨论。

搜索指南

基本搜索

在搜索框中输入关键词，系统会自动搜索开发板名称、描述、芯片架构以及项目名称、描述和标签。

搜索类型筛选

点击搜索框右侧的下拉菜单，选择"开发板"或"项目"，可以只搜索特定类型的内容。

热门搜索

在搜索页面，我们提供了热门搜索标签，点击即可快速搜索相关内容。

开发板使用

查看开发板详情

点击开发板卡片即可查看详细信息，包括技术规格、外设接口、支持的开发框架以及相关开源项目。

开发板对比

在开发板列表页面，勾选多个开发板的复选框，然后点击"对比选中的开发板"按钮，即可查看参数对比表格。

开发资源

在开发板详情页面，我们提供了官方文档、SDK下载、视频教程和社区论坛的入口链接。

项目使用

查看项目详情

点击项目卡片即可查看详细信息，包括项目描述、Stars数、Forks数、许可协议以及编译状态。

收藏项目

登录后，点击项目详情页面的收藏按钮，即可将项目添加到个人收藏列表中。

分享项目

点击分享按钮，复制项目链接分享给其他开发者。

发表评论

登录后，在项目详情页面的评论区发表您的评论和建议。

账号管理

注册账号

访问注册页面，输入用户名、邮箱和密码即可创建账号。用户名长度应在3-20个字符之间，密码至少8个字符。

登录账号

访问登录页面，输入用户名和密码即可登录。支持显示/隐藏密码功能。

个人中心

登录后，点击页面顶部的用户名即可进入个人中心，查看收藏的项目和修改个人设置。

设置技能水平

在个人中心的设置页面，选择您的技能水平（入门/中级/高级），系统会根据您的技能水平推荐适合的项目。

常见问题

ZouIC 是一个开源开发板聚合平台，致力于为全球开发者提供一站式的硬件开发资源服务。我们收录了 67 款主流开发板和 1513 个开源项目，帮助开发者快速找到适合的硬件和项目资源。

您可以访问开源开发板页面，按厂商或芯片架构进行筛选。每个开发板都有详细的技术规格和参数，您可以根据项目需求选择合适的开发板。我们还提供了开发板对比功能，可以同时查看多款开发板的参数对比。

目前我们正在开发项目提交功能。请关注我们的更新，届时您可以通过平台提交您的开源项目，与全球开发者分享您的作品。

平台的数据主要来自GitHub等开源代码托管平台，以及官方开发板文档。我们定期更新数据，确保信息的准确性和时效性。

如果您发现平台上的数据有误，请通过联系我们页面提交反馈。我们会尽快核实并修正错误。

API接口

概述

ZouIC 提供RESTful API接口，允许开发者获取开发板和项目数据。所有API接口均返回JSON格式数据。

基础URL

所有API接口的基础URL为：/api/v1

接口列表

接口路径 方法 描述
/api/v1/boards GET 获取开发板列表
/api/v1/boards/{id} GET 获取开发板详情
/api/v1/projects GET 获取项目列表
/api/v1/search GET 搜索开发板和项目
/api/v1/favorites POST 添加收藏（需登录）
/api/v1/favorites/{id} DELETE 取消收藏（需登录）

请求示例

curl -X GET "https://www.zouic.com/api/v1/boards?page=1&per_page=10"

响应示例

{
  "data": [...],
  "total": 100,
  "page": 1,
  "per_page": 10
}
