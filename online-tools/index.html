常见问题

不装电脑环境，浏览器能烧 ESP32 固件吗？

能。Chrome / Edge 通过 Web Serial 直连芯片，选好板型或本地 bin 就能写入，省掉驱动、下载模式与烧录地址这几关。本站收录的在线烧录入口与浏览器串口终端都走这条路径，能力边界基本由乐鑫官方的 esptool-js（Apache-2.0）决定。

第三方站烧录的小智 AI 固件是开源的吗？

固件本体是开源的：仓库 78/xiaozhi-esp32 为 MIT 许可，配套后端 xiaozhi-esp32-server 同为 MIT（均为 2026-11-01 经 GitHub API 实测）。第三方站提供的是烧录服务与固件打包，这不改变上游许可，也不代表它们分发的每个固件包都开源——社区上传的固件要逐个看它的仓库与许可说明。

这些在线工具收费吗？

按 2026-11-01 各页面上看得见的文字记录：烧录与信息读取类页面没有出现登录门槛或收费提示；串口终端登录后可以保存常用命令；芯片对拷要先解锁复刻权限；NVS 分区读取需登录，而修改、写回是付费功能；固件市场同时存在免费与付费固件，付费固件按项目扣除站内积分、可用会员订阅畅用；对话式生成的 MicroAgent 有免费额度、用满也不会中断对话，需要更多算力可以订阅 AI 套餐，也支持填自己的模型 API Key；托管 MQTT 按年订阅、到期自动停权，控制面板依赖这项订阅。凡是本页标「未标注」的条目，都表示我们在页面上没有找到收费信息，价格以站内为准。

用别人服务器烧固件、备份 Flash 有什么要注意的？

两件事。一是设备存储会被完整读取，导出的 bin 版权归原固件作者，别随手分发；二是对拷与克隆只应针对你自己拥有权利的设备与固件。需要长期依赖时，建议本地同时留 esptool / esptool-js 作为兜底，不把产线和交付绑在第三方站上。
