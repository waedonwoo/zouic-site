先说结论：按“目的”选来源，而不是按名气

很多人找开源硬件项目的第一反应是搜 GitHub。但 GitHub 只解决“代码在哪”，不解决“这个东西做出来了没有”“能不能买到”“有没有人复现成功”。不同来源承载的东西不一样：有的给代码，有的给成品教程，有的给趋势，有的给能下单的实物。

ZouIC 现在收录 250 条开源硬件条目（外部平台 222 条 + 站内开源开发板 20 块 + 实战案例 8 个，数据为 2026-10-27 快照，随同步更新）。拆开看来源，每个平台的性格很清楚。

四条使用路线

  • 要能立刻跑起来的代码：去 GitHub 来源页，按主控筛选。站内 ESP32 相关条目最多（83 条），AI 硬件方向 61 条。
  • 要照着做一遍：去 Hackster.io 来源页，项目页通常自带步骤与物料。
  • 要看今年在发生什么：去 Hackaday 来源页，这里多是社区报道，适合找方向而非找代码。
  • 要买一块开源硬件：去 CrowdSupply 来源页，注意先看它的开源范围与交付状态。

ZouIC 怎么收录这些项目

  • 只做收录与索引：不托管代码与文件，点击标题跳回原平台；版权与授权归原作者。
  • 按原页 URL 去重：同一项目只保留一条，不做合并猜测。
  • 许可证不猜测：仓库里写明 MIT / Apache-2.0 / GPL-3.0 的照录；原页面没写清的，一律标注“以原页面标注为准”。
  • 如实标注性质：Hackaday 条目会标明“报道文章，非代码仓库”，避免被当成可 clone 的源码。

常见问题

这些项目是 ZouIC 自己做的吗？
不是。全部条目来自各平台公开页面，ZouIC 只做收录、整理与索引，点击即跳回原平台。
收录数字会变吗？
会。各来源会随同步更新，页面上的数字以来源页实时显示为准，本文为 2026-10-27 快照。
为什么 Hackaday 的条目没有仓库链接？
Hackaday 是社区媒体，条目多为报道文章而非代码仓库。需要点进原文找作者给出的仓库与设计文件链接。
想贡献一个项目怎么操作？
