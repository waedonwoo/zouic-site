人形与四足机器人开源项目清单：8 个能真正跑起来的仓库

不是渲染图，是能 clone 下来跑的仓库

极客微栋 @GeekWaedon · 2026-10-27

先说口径：这 8 个里不全是“人形”

坦白讲清楚：ZouIC 目前机器人方向收录 8 条，站内归入“人形机器人”这一类，但其中既有人形/双足，也有四足与桌面小机器人。这里如实标注形态，不做包装，因为对想动手的人来说，形态比标签重要。

共同点是：全部来自 GitHub 真实仓库，许可证明确，不是概念视频。

许可证差别，比性能差别更影响你能做什么

  • MIT（4 个）与 Apache-2.0（2 个）：宽松，保留声明即可，改了固件可以闭源分发；Apache-2.0 还附带明确的专利授权。
  • GPL-3.0（2 个）：ElectronBot 与 Roboto Origin。你改了代码并对外分发，就要以同一许可证公开源代码——打算做成品售卖的，这一步必须先想清楚。
  • 硬件部分另算：上表是代码仓库的许可证，结构件与电路可能另有硬件许可证，复刻前请回到仓库确认。

上手建议

  1. 先读仓库的 README 与 BOM，确认零件是否买得到、是否需要 3D 打印或 CNC。
  2. 从四足或桌面型起步：Stanford Doggo、OpenCat 这类结构相对简单，调试成本低于双足。
  3. 双足先看仿真：Berkeley Humanoid Lite、ToddlerBot 通常提供仿真环境，先在仿真里跑通再上实物，省下摔机成本。
  4. 主控选型：ESP32 类项目成本最低，可对照站内 ESP32-S3-DevKitC 看参数。

常见问题

这 8 个都能直接买到成品吗？

不都能。它们是开源仓库，需要自己准备物料制作；是否同时有商品化产品，以各项目主页说明为准。

新手适合从哪个开始？

结构最简单的四足或桌面型更友好，例如 Stanford Doggo、OpenCat ESP32。

GPL-3.0 项目我能做来卖吗？

售卖本身通常不被禁止，但你修改并分发固件时，需要按 GPL-3.0 提供源代码。硬件部分还要看它选用的硬件许可证。

许可证写错了吗？

如发现与仓库当前 LICENSE 不一致，请通过 贡献指南 反馈，我们会核对后修正。
