为什么关注 RISC-V

RISC-V 是开源、免费、可扩展的指令集架构，不受单一厂商绑定。2026 年它在 MCU 与边缘计算两端都在加速落地，从几块钱的 CH32V 到能跑 Linux 的 StarFive 应有尽有。

站内能查到的 RISC-V 板子

开发板定位看点
CH32V307入门 MCU国产、便宜、带以太网，适合学生与低成本控制
GD32VF103入门 MCU兆易创新，兼容生态，GPIO 丰富
SiFive HiFive 2评估 / 教学RISC-V 奠基公司出品，生态成熟
StarFive VisionFive 2Linux 单板四核、能跑完整 Linux，可作小型开发主机

选型建议

  • 学指令集 / 低成本实验：选 CH32V307 或 GD32VF103，几十元入门。
  • 做教学 / 评估：SiFive HiFive 2 文档与工具链最完善。
  • 跑 Linux / 边缘网关：StarFive VisionFive 2 是唯一现实选择。

常见问题

RISC-V 开发板和 ARM 板最大区别？
RISC-V 指令集开源、可自由扩展，ARM 需授权；软件生态 ARM 更成熟，RISC-V 追赶很快。
RISC-V 能跑 Linux 吗？
可以，64 位 RISC-V（如 StarFive VisionFive 2）已有较完整的 Linux 发行版支持。
