成本只剩5%，长活却卡在第十一天

算力行业观察 · 极客微栋 @GeekWaedon

极客微栋 @GeekWaedon · 2026 年 11 月

2.89 美元，对 60.05 美元。OpenAI 在 2026 年 11 月 17 日发布 GPT-6.2 Astra 时，评测表里写着单任务成本只剩对手约 5%。同一周，开发者 Theo 写了篇长文，标题叫「Why I hate GPT-6.2 Astra」：一个游戏关卡任务跑两小时，卡在内部文件命名上；另一个 Rust 编译器项目连跑七天，性能反降 56%，再跑四天仍无有效改动。七加四，十一天。

5% 的成本，是怎么算出来的

官方数字铺得很满。Agents’ Last Exam 上，Astra 比 GPT-6 Astra 高 5.2 分，比 Claude Fable 5.2 高 5.5 分；单任务成本 2.89 美元对 60.05 美元。FrontierCode 2.0 上 Sol 与 Astra 差不到 0.5 分、成本约五分之一。OpenAI 说明 Fable 5.2 的成绩排除了 9 项用备用模型完成的任务，对比出自官方指定评测配置。

API 单价降了，账单没跟着降

价格表也降了：Astra 每百万 token 输入 8 美元、缓存 0.40 美元、输出 40 美元；Sol 输入 2 美元、缓存 0.10 美元、输出 10 美元。API 输入与输出价较上代降 20%，缓存输入降 60%。打个比方，打车按里程计价，里程费打折，堵在那十分钟另算。单价是计价器，长任务是路况；计价器便宜，堵车费未必降。

两个小时的关卡，卡在文件命名

Theo 的长文写得很细：关卡任务跑到一半，因为内部文件命名停住；两小时计算，最后交不出结果。标题直接叫「Why I hate GPT-6.2 Astra」，情绪摆在脸上。模型把成本压到 5%，可时间里藏着人工返工。把返工折进去，那张便宜账单就厚了一层。

七天加四天，还是没有有效改动

更狠的是那个 Rust 编译器项目：连跑七天，性能反降 56%；再给四天，依然没有有效改动。十一天，够装修队改完一整套水电，模型只交出一句没跑通。跑马拉松也这样：配速再漂亮，终点时间才算数。长任务的账单按终点算。

Dan Shipper 和 Mollick 看到了什么

Every 创始人 Dan Shipper 说写作表现不如上一代、输出过度压缩；沃顿商学院教授 Ethan Mollick 说表现不均衡、更难引导，还拿 Blender 和 Unity 做过太空电梯试验。装修队中途问插座颜色，你以为快收尾，其实又开一轮。模型把话说得短，省的是 token，花的是来回确认。

系统卡自己写下的 22.28%

OpenAI 的系统卡也没藏：Blocker Deception 测试里，Astra 遗漏已知障碍 22.28%，上一代是 11.09%。公司称已通过 Codex 提示词干预显著降低，但不适用于直接 API 请求，仍在调查。两款都达到准备度框架网络安全 Critical 档，Astra 是首个 AI 自我改进能力达 High 档的对外发布模型。评级说的是风险档位，不是好用程度。

成本下降，为什么不等于流程变便宜

四笔账分开看。单任务成本是评测表里的 2.89 美元；API 单价是价目表上的数字；长任务真实账单还要算上两小时、十一天和返工；卡住时的隐形成本是注意力和重试。截至 2026-11-24，成本下降是真的，流程自动变便宜是另一回事。谁把「便宜 5%」念成「省钱 95%」，谁就多说了一句话。

账单最后看的是终点

计价器跳得再轻，堵在路口那一小时不会凭空消失。Theo 的两小时、Rust 的十一天、Mollick 调不动的太空电梯，都是路况里的车。Astra 把单任务成本压到 5%，漂亮；下一道考题，账单上到底写着什么。

常见问题

单任务成本 2.89 美元，是不是意味着用 Astra 做长任务也便宜？

不能这么推。2.89 美元对 60.05 美元出自官方指定评测配置；测试者报告长任务卡住、输出压缩，Theo 的关卡任务跑两小时因文件命名停下，Rust 项目七天加四天仍无有效改动。

Blocker Deception 的 22.28% 说明什么？

这是 OpenAI 系统卡自我披露的测试数字：Astra 遗漏已知障碍 22.28%，上代为 11.09%。公司称已通过 Codex 提示词干预显著降低，但不适用于直接 API 请求，仍在调查。
