问天 G6 到货，先验六项配置

算力行业观察 · 极客微栋 @GeekWaedon

极客微栋 @GeekWaedon · 2026 年 11 月

问天 G6 到货，容易把发布会口径当成验收指标。环球网报道经新浪财经 2026-11-16 转述，发布会 2026-11-12，联想展出问天 WR6215 G6 与 WR5225 G6，另有 WA5685 G5、WA70165 G5 机型。单路与双路决定核心上限与 GPU 数量，内存插槽、CXL 与 PCIe 通道要看具体 BOM，厂商给的倍数与能效数字带场景。六项配置先验清楚再签认

适用条件，先定单路还是双路

适用条件先定路数。WR6215 G6 是 2U 单路，搭载第六代 AMD EPYC 9006 系列，最高 256 核；WR5225 G6 是 2U 双路，两颗 EPYC 9006。单路的核数上限与双路不同，GPU 上限也要按机型看：WR6215 G6 最高 4 张双宽或 8 张单宽卡，WR5225 G6 最高 4 张双宽卡。订单里写清是哪一款，再用对应上限做核对。

准备，核对 SKU 核数与插槽实配

准备阶段先核两件事：具体 SKU 的核心数，以及板卡是否把宣称的插槽全部实配。WR6215 G6 给出 16 个 DDR5 RDIMM 插槽，WR5225 G6 最高 32 个 DDR5 插槽；插槽数写在口径里，实装几条要看 BOM。同样要确认 24 板载直连 NVMe、OCP 与 PCIe Gen6 槽位是已配还是预留。把宣称值和实配值分两列记，验收才有基准。

准备，谁来核 BOM、谁来实测

准备还要定人。系统工程师核 SKU、核心数与 BIOS 微码版本；硬件工程师核 DIMM 实插、CXL 槽位、PCIe Gen6 物理通道与 GPU 卡数；运维核散热方案、NVMe 数量与 OCP 模块。厂商经权威媒体转述的口径给上限与能力，现场清点给实际配置，两者不能互相替代。每类检查留一名签字人，异常才有归口。

准备，把发布日与验收日分开

时间点分开记。2026-11-12 是发布会，2026-11-16 是环球网报道经新浪财经转述的日子，两者都是口径节点；验收排在到货之后，按实际机器做。基准日 2026-11-23 是本站核查时点，不是发布或交付时间。把发布日写成到货日，会让六项配置在还没清点时就被签认。

记录，六项配置落在同一份清单

记录按六项落表：路数与 SKU 核心数、DIMM 实插数量与速率、CXL 是否实配、PCIe Gen6 通道与 GPU 卡数及单卡 TDP、NVMe 数量、OCP 模块与散热方案。WA5685 G5 给出 8 到 10 张 600 W 双宽卡、13 个 PCIe 槽位与风冷或液冷，WA70165 G5 为 10U、16 张 600 W TDP 双宽卡，这些按机型另记一列。厂商倍数与能效数字不混进这张表。

步骤，逐项核对内存与扩展能力

步骤逐项走。先看 MRDIMM 12800 MT/s 是否在具体 CPU 与内存 BOM 上被支持，8000 MT/s DDR5 与 12800 MT/s MRDIMM 是两档，别按最高档签收。再看 CXL 槽位是已插设备还是只留位置。然后数物理 PCIe Gen6 通道，对照 GPU 卡数与单卡 TDP，确认供电与散热余量。最后核 NVMe 与 OCP 模块清单，每项留现场记录。

异常处理，先查 BOM 与 BIOS 再升级

异常处理按这个顺序。GPU 卡数或内存速率低于口径，先查 BOM 与 BIOS、微码版本，再决定是否升级或申诉，不直接按上限判不合格。整系统性能较上一代最高提升 78%、单路内存带宽最高 1.6 TB/s、318 项性能世界纪录、海神液冷 PUE 低至 1.04 且散热上限提升超过 50%，均为厂商口径场景值，未给统一基线，不作验收值。

复核后按六项结果建验收基线

复核看的是实测与口径的差。把六项配置的现场清点与厂商口径分栏保存，差异项写清 SKU、BOM、BIOS 版本与测试场景。单路或双路、插槽实配、CXL 状态、通道与卡数、NVMe、OCP 与散热，逐项签认后才形成这台机器的验收基线。厂商倍数与 PUE 数字进备注栏，不进验收栏。价格与交付时间本文不记。

常见问题

WR6215 G6 的 256 核是不是到手就有？

不是。256 核是 WR6215 G6 搭载第六代 AMD EPYC 9006 系列时的最高核数口径，实际核心数取决于具体 SKU。WR5225 G6 是双路机型，两颗 EPYC 9006，核心上限按两颗算。到货先核 SKU 与 BIOS、微码版本，再与合同配置比对。

MRDIMM 12800 MT/s 能直接写进验收吗？

不能。8000 MT/s DDR5 与 12800 MT/s MRDIMM 是两档能力，是否支持要看具体 CPU 与内存 BOM，插槽数也不等于实插数。先确认板卡实装几条、速率档位落在哪一档，再决定是否作为验收项。CXL 槽位同理，要区分已插设备与预留位置。

78%、1.6 TB/s、318 项纪录和 PUE 1.04 怎么用？

作为厂商场景值记录，不作验收值。这些数字来自厂商口径经权威媒体转述，未给统一基线、负载与场景；整系统性能较上一代最高提升 78%、单路内存带宽最高 1.6 TB/s、318 项性能世界纪录、海神液冷 PUE 低至 1.04 且散热上限提升超过 50%，都要先拿到测试基线与场景再评估。
