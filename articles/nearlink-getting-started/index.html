星闪是什么

星闪（NearLink，代号 SparkLink）是面向短距通信的新一代标准，主打低时延、高并发、低功耗，常用于鼠标、车钥匙、工业传感等场景，是蓝牙 / Wi-Fi 的有力补充。

站内的星闪开发板

板子角色用途
NearLink DevKit Pro开发套件全功能评估，跑通首次通信
NearLink Gateway网关多节点汇聚、桥接上位机
NearLink Sensor Node传感节点采集 + 低功耗上报

起步路径

  1. 用 DevKit Pro 跑官方示例，确认能看到第一缕数据。
  2. 加一个 Sensor Node 做低功耗采集端。
  3. 用 Gateway 把多节点汇聚到上位机 / 云端。

常见问题

星闪和蓝牙怎么选？
星闪时延更低、并发更强，适合对实时性敏感的场景；蓝牙生态更普及，适合消费配件。
NearLink DevKit Pro 适合新手吗？
它定位全功能评估，资料较全，是上手星闪最稳妥的起点。
