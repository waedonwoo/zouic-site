中端模型87.4分登顶，旗舰价签贵了三倍多

算力行业观察 · 极客微栋 @GeekWaedon

极客微栋 @GeekWaedon · 2026 年 11 月

菜单上多了一行小字：87.4分，2.654美元。这是 Gemini 4 Neon 在 LiveBench 2.0上的成绩和每成功任务成本。同一张榜单上，两家旗舰并列84.9分，其中一家的成本是9.850美元。分数差2.5，账单差三倍多。这张价签到手，看榜的方式就得换一换。

总分领先了多少？

LiveBench 2.0于11月6日发布，截至基准日仍是最新一版。Gemini 4 Neon 的 xhigh 档以87.4分排在总榜第一，Claude Fable 5.2与 GPT-6.2 Astra 同为84.9分，落后2.5分。榜单共7个套件，5个是 agent 长程任务、2个是短问答，长程任务按双倍加权，编码与设计按1.5倍加权。这套权重说明榜单想量的并非单次答题，是持续做事。把长程任务双倍加权之后，2.5分的领先才有了具体含义：它出现在需要连续调用工具的场景里，并非某个短问答的灵光一现。

分项都赢在哪儿

分项上，Neon 浏览器使用95.6分排第一，研究94.5分与 Fable 5.2并列第一，编程89.7分。它的长程套件拿到82.6分，比 Carbon 的71.8分高出10.8分。这10.8分比总分那2.5分更能说明问题：Google 这一代优化的是持续操作的能力，选择题答得快未必能转化成浏览器里连续二十步不跑偏。一个 agent 在点外卖时要找店、选规格、填地址、确认支付，每一步都可能掉链子，长程套件的分数就是把这些掉链子的概率折成了数字。

一个成功任务多少钱？

成本这一栏更值得盯。Neon 每成功任务成本2.654美元，Fable 5.2是9.850美元，Astra 是1.941美元。Neon 约为 Fable 的27%，不到三成。这里写的是“每成功任务”，分母是成功的那些任务，失败调用的消耗没有摊进来。截至 2026-11-26，三家都没有公开同一批任务上的失败率口径，所以这个数字可比，但不可全信。

价签上写着什么价

再看 API 单价，这是一张完全不同的价签。按每百万 token 计，Neon 输入3美元、输出15美元；Fable 5.2输入8美元、输出40美元；Meta 的轻量档 Muse Ember 短输入低至0.10美元、输出0.50美元，据开发者测评口径，旗舰与轻量之间相差约80倍。三行数字摆在一起，菜单的结构就出来了：旗舰冲高、中端卡位、轻量走量。80倍并非降价幅度，是两种完全不同任务的市场定价。还有一列不能漏：Astra 的每成功任务成本是1.941美元，低于 Neon，但它的 API 单价并未在该窗口披露。这说明任务成本和调用报价不一定同向，跑同样一批任务，先按单价估算和按成功率估算，可能得出相反的结论。

三套口径别混成一张表

榜单总分、每成功任务成本、API 单价，这三样东西经常被塞进同一张性价比表里求平均，这么做等于把考试分数、饭钱和菜价混成一个数。榜单分数评的是能力，任务成本评的是完成一件事的综合消耗，API 单价评的是调用报价。同一个模型在三套口径里可以排三个名次。要比较就得先问清比的是什么任务、什么上下文、失败算不算钱。口径不一致时，最精确的数字反而最误导。

11月为什么挤满新品

这张价签是11月集体上新之后才出现的。据行业梳理，海外 Anthropic 推 Mythos 5.2与 Fable 5.2，OpenAI 双线 GPT-6.2 Astra 与 Sol，Google 几周内连发四款 Gemini 4，Meta 切入超低价轻量赛道 Muse Ember；国内腾讯推 Hy4与 Hy4 Flash，阿里重写底层架构的 Qwen4-Max，智谱 GLM-5.4首用 Loop Transformer，月之暗面 Kimi K3.1 Pro，百度 ERNIE 5.5 Flash Preview，美团 LongCat-2.5。同一时段塞进这么多型号，厂商要抢的并非榜首，是价位段。

谁该看哪一行

对做科研和长程攻坚的团队，旗舰的高单价未必是浪费，那些任务失败一次的成本远高于 token 钱。对跑日常 agent 的团队，Neon 这类中端档位的意义更大：长程能力接近旗舰，成本不到三成。对高频短调用的场景，轻量的80倍低价才是真的门槛。选型顺序应该倒过来：先定任务类型，再看对应档位，最后才看谁的分高。拿着总分去选低价调用，等于用米其林评分挑早餐店。

下一张菜单怎么读

Neon 的意义不在又一个第一，在中端第一次在长程 agent 榜上赢了旗舰。这一件事背后有个更实用的判断：当评测从静态问答转向长程任务，推理策略的 effort 分档和工具调用稳定性，比参数规模更决定名次。下次再看榜单，先翻到权重说明那一行，弄明白它到底奖赏什么。菜单上写着87.4分，真正决定你付多少钱的，是那2.654美元对应的任务类型。分数会过时，榜会换版，价目表也会跟着改。能留下来的只有这件事：先弄清任务，再选档位。把顺序反过来的人，会在每一轮上新里重新付一次学费。

常见问题

87.4分意味着中端模型已经全面超过旗舰吗？

不能这样推。LiveBench 2.0总分中 Neon 领先2.5分，优势集中在按双倍加权的长程套件，浏览器与研究等分项有领先也有并列。榜单只覆盖7个套件，不等于全部任务类型。更稳妥的说法是：在长程 agent 这一类任务上，中端档位拿到了可比较的成绩。

2.654美元和3美元每百万 token 哪个更该看？

看你要算什么。每成功任务成本是完成一个任务的综合消耗，API 单价是调用报价，两者分母不同。前者用于估算一个具体应用的月度账单，后者用于比较同一批输入输出的报价。把两者混在一张表里求平均会失真。
