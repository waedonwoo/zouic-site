49.95和55.95美元的P4板，先查补丁

算力行业观察 · 极客微栋 @GeekWaedon

极客微栋 @GeekWaedon · 2026 年 11 月

49.95 美元和 55.95 美元，差的那一块落在射频模组和网口上，芯片还是同一颗。SparkFun 在 2026-11-06 发布两款 IoT RedBoard，均基于 ESP32-P4NRW32X，都做成 Uno R3 板型。截至 2026-11-24，据 CNX Software 与 FOSSWire 转述，两款在官网列为有货。便宜的配 ESP32-C5，贵的配 PoE 以太网。先把一句话写在纸上：你的项目走哪条网？

六美元差价，买的到底是什么

共同部分先摊开。ESP32-P4NRW32X 里有双核 400MHz 高性能 RISC-V、40MHz 低功耗核、768KB HP L2、32MB PSRAM、16MB flash，带 2D PPA、H.264/JPEG 编解码和 microSD。32MB PSRAM 大约等于二十多张 1.44MB 软盘。两款还共有 Uno R3 排针（16 数字、6 模拟）、双 USB-C（HS OTG 与 Serial/JTAG）、Qwiic、LiPo 充电与电量计（MCP73831 加 MAX17048）、7 至 15V DC 输入和 WS2812B RGB。买车选四驱还是雪地胎，底盘一样，差价全在路况。别急，往下看各自多出来的那部分。

装进盒子的那一刻，你会想起量尺寸

板型是 Uno R3，尺寸 68.6×58.4mm，双 USB-C、Qwiic 和 microSD 都占边缘位置。装修前先确认插座在哪，否则柜子做好了才发现插头被挡住；装这块板也一样，先拿尺子量外壳，再决定 USB-C 朝哪边、Qwiic 线从哪走。LiPo 充电与电量计已经板上集成，若靠电池供电，还要想清楚 7 至 15V DC 输入和外部电池怎么切换。WS2812B 那颗灯别当成装饰，它是到手第一眼判断有没有上电的凭据。先把机械位置定下来，再谈软件。这一步最容易被跳过。

走哪条网：无线版和 PoE 版是两根不同的线

无线版 DEV-30909 靠 ESP32-C5-WROOM-1 经 SDIO 接 P4，支持 2.4/5GHz Wi-Fi 6、蓝牙 5 LE 和 802.15.4（Zigbee、Thread）；板上留了串口排针给 C5 烧录，P4 与 C5 各有 Boot 与 Reset。这里有个坑：ESP32-P4 本身不带射频，想用 5GHz，得先把 C5 跑通。PoE 版 DEV-30910 用 TI DP83825 PHY 加 MagJack RJ45，供电来自 Silvertel Ag9905M 的 802.3af 模块，36 至 57V 输入、5V/1.8A 输出，约 9 瓦，跟一只小灯泡差不多。插线板和网线两种接法：一个解决插座不够，一个解决布线太远。翻出现场照片看一眼，网线已经铺到墙里，就别为省六美元改无线方案。态度很明确：网走不通，其他都是白搭。

3.3.12 那行补丁，决定 5GHz 和以太网能不能跑

两款出厂预装 MicroPython，也支持 ESP-IDF 与 Arduino IDE。听上去齐全，但报道指 Arduino Core 3.3.12 需要补丁，才能用 C5 的 5GHz Wi-Fi 与 PoE 以太网。报道写得很直白：「当前需要补丁才能用 C5 的 5GHz Wi-Fi 与 PoE 以太网」。这句话要读两遍。开发者要做的是下载补丁、重新编译、再跑扫描，别插上板子就以为万事大吉。最容易被忽略的一点：板子能点亮，不等于 5GHz 和以太网能跑。SparkFun 放出产品时也公开了原理图与 KiCad 文件（据 FOSSWire 转述），补丁才有下手处。先确认 Core 版本号，再去翻仓库，顺序别反。

图纸公开，才谈得上自己修

原理图和 KiCad 文件公开，价值要放到出问题那天才看得出来。宜家家具附的图纸让你对着零件一步步装回去，没有图纸，少一颗螺丝就只能整个扔掉；开发板同理，有 KiCad 文件，你能顺着丝印查引脚、改飞线、复现最小系统。SparkFun 放出开源硬件文件，开发者不必只等下一版固件。动作很简单：下载文件，核一遍 C5 的 SDIO 引脚和 RJ45 的 PHY 连接，再跑最小的 Wi-Fi 扫描或以太网链路例程，把结果记下来。先存到本地，花不了几分钟。

通电三分钟，先做一轮粗筛

到手第一轮只做粗筛。拆封后看板子与排针有没有磕碰，量一下尺寸；接 7 至 15V DC 或 USB-C，看 WS2812B 亮不亮、串口有没有 MicroPython 提示符；再跑 2.4GHz 与 5GHz 扫描，看 C5 是否都被识别；PoE 版插网线，看链路灯和协商速率。每一步写进同一张表，字段四列：项目、条件、结果、版本号。别追跑分，这块板的价值在接口齐不齐、补丁能不能打、资料能不能复现。三轮下来，你会比看十篇开箱文更清楚它适不适合自己。先通电，再判断。

哪些项目该绕开这两块板

边界也要写清楚。PoE 版配的是 10/100 以太网，现场已经铺了千兆线，它的网口就跑不满。需要 5GHz 又不想碰补丁，Arduino IDE 眼下不顺，适合换成 ESP-IDF 或先备好补丁。要跑 Matter 或 Thread，得确认 C5 的 802.15.4 在你用的协议栈里可用，板上硬件支持与软件可用是两件事。这块板子卖的是两种联网方案，芯片本身并不新，冲着 ESP32-P4 型号来的人，先看清楚自己要的射频在不在板上。把 PoE 当卖点之前，先看网线能不能供电。

最后怎么选：一张纸写完再下单

把四行字写在纸上：装哪里、走哪条网、补丁打没打、图纸在不在。写完你会发现，六美元差价排在最后面。真正决定的是网线有没有铺到墙里，是 5GHz 的补丁你愿不愿意打，是出问题那天手上有没有 KiCad 文件。SparkFun 已经把板和文件都摆出来了，开发者要回答的却是自己的现场问题。箱子还没拆，先别点下单键；你打算把这块板交给谁，在什么环境下第一次通电？

常见问题

无线版和 PoE 版该怎么选？

先看现场。无线版 DEV-30909 靠 ESP32-C5 提供 2.4/5GHz Wi-Fi 6、蓝牙 5 LE 与 802.15.4，适合没有网线、需要 Zigbee 或 Thread 的现场；PoE 版 DEV-30910 走 10/100 以太网和 802.3af 供电，适合网线已铺好、一根线同时解决数据和电力的位置。49.95 与 55.95 美元只差六美元，远不如现场有没有网线重要。若现场是千兆布线，PoE 版的 10/100 网口跑不满，要单独确认。

Arduino Core 3.3.12 的补丁会影响什么？

据媒体转述，Arduino Core 3.3.12 当前需要补丁，才能用 C5 的 5GHz Wi-Fi 与 PoE 版的以太网，受影响的是这两条通路。处理顺序：先确认 Core 版本号，再下载补丁重新编译，最后跑一次 5GHz 扫描或以太网链路测试并记录。若暂时不想碰补丁，可先评估 ESP-IDF 路径是否够用。

出厂预装 MicroPython，还要不要验 Arduino IDE？

要验。预装 MicroPython 只说明上电能进交互环境，不代表 Arduino IDE 路径可用。两款都支持 ESP-IDF 与 Arduino IDE，但报道指 Arduino Core 3.3.12 对 5GHz 和以太网仍需补丁。到手先跑串口确认 MicroPython 提示符，再装 Arduino Core 跑最小例程，看编译、烧录是否顺畅，别拿预装环境代替软件栈核验。
