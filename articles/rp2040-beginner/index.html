为什么推荐 RP2040

RP2040 是树莓派基金会推出的双核 Arm Cortex-M0+ 微控制器，价格极低、资料极全、PIO 外设独特，非常适合入门与创客项目。

第一个 MicroPython 程序

烧录 MicroPython 固件后，用 Thonny 连接，输入：

from machine import Pin
import time
led = Pin(25, Pin.OUT)
while True:
  led.toggle(); time.sleep(0.5)

即可让板载 LED 闪烁。下一步可以接传感器、读 I2C、做小车——Demo 项目库里有不少 Pico 灵感。

常见问题

RP2040 和 Arduino 比哪个好入门？
两者都友好；RP2040 性能更强、价格更低，但 Arduino 生态更庞大。新手从兴趣点选即可。
Pico W 的 Wi-Fi 好用吗？
板载无线开箱即用，MicroPython 里有现成网络库，做联网项目很方便。
