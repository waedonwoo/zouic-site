155 万 token/秒背后：推理的经济学，正在改写 GPU 的定价逻辑

算力行业观察 · 极客微栋 @GeekWaedon

极客微栋 @GeekWaedon · 2026-10-27

核心观点：GPU 的定价逻辑正在从"卖 FLOPS"转向"卖 token"。基准测试的最高分不属于算力最强的芯片，属于每百万 token 综合成本最低的系统——这个转变会重塑未来三年的采购与产品路线图。

从两组基准数据说起

MLPerf Inference v6.0 的两个标志性成绩：英伟达 GB300 NVL72（288 GPU）在 DeepSeek-R1 服务器场景跑出约 155 万 token/s；AMD 用 94 张 MI355X 突破 100 万 token/s，并在 MLPerf 6.1 用 512 张 MI355X 刷新 GPT-OSS-120B 聚合吞吐纪录。同时，GB300 官方口径称相比 Hopper：用户响应速度（每用户 TPS）提升 10 倍、每 MW 吞吐提升 5 倍。

注意"每 MW 吞吐"这个指标——它就是 token 经济学的核心。当机柜功率密度突破 120kW、电力成为 AIDC 第一运营成本时，每瓦特、每美元电力产出的 token 数，比峰值 FLOPS 更接近采购真相。

每百万 token 成本的四个变量

  1. 硬件折旧摊薄：吞吐越高，同样折旧周期内产出的 token 越多——GB300 对 Hopper 5 倍的每 MW 吞吐提升，直接改写折旧公式；
  2. 电力成本：1400W 单芯片热耗与液冷能效（约 40% 提升）共同决定电力在成本结构中的占比；
  3. 内存容量与上下文：长上下文场景 KV Cache 吃内存，MI355X 的 288GB 对 B200 的 192GB 意味着单卡并发数差异——单位 token 的内存摊销不同；
  4. 软件效率：FP4/FP8 量化、解耦推理架构（如 Dynamo Prefill/Decode 分离）的工程成熟度，同样能带来百分之几十的吞吐差异——不花硬件钱就能白拿的收益。

这也解释了 AMD 收购 Taalas（把权重固化进硅片）的动机：推理专用路线的本质，是把"每 token 成本"压到通用架构的理论下限之下。

总结

推理经济学给所有玩家重排了座位：英伟达赢在每 MW 吞吐，AMD 赢在内存摊销，自研 ASIC 赢在去掉利润层，国产超节点赢在电力与供给。采购方的正确姿势是放弃"谁的芯片最强"之争，直接测算自己负载下的每百万 token 综合成本——这个数字，才是 2026 年之后算力世界的通用货币。

常见问题

为什么说 GPU 定价逻辑在变？

推理成为主流负载后，客户关心的从峰值算力变为每百万 token 的综合成本（硬件折旧 + 电力 + 运维），基准成绩与报价单都在向这个口径迁移。

每 MW 吞吐是什么指标？

每兆瓦电力投 入产出的 token 吞吐量，英伟达宣称 GB300 NVL72 相比 Hopper 平台提升 5 倍；它是衡量算力系统能效的核心指标。

小团队需要关心这些吗？

需要。即使通过云厂商按 token 计价购买，云厂商的成本结构最终会传导到单价；理解成本构成有助于判断云报价的合理性。
