Community contribution guide

Join the open-source hardware ecosystem — build, share, and grow together

Why contribute

Learn and grow

Work on open-source projects and exchange ideas with developers worldwide while deepening your knowledge of hardware design, software development, and system architecture

Community recognition

Your contributions will be seen and used by developers around the world, building your personal brand and technical influence

Drive innovation

Help strengthen the board ecosystem and bring more great hardware projects to life

Career growth

Open-source contributions carry real weight in a job search, showcasing your technical ability and teamwork

How to contribute

1

Pick a project

Browse the open-source project gallery for something that interests you, and learn about its needs and technical direction

Browse Projects
2

Read the docs

Read the project README, contribution guidelines, and coding standards to understand its architecture and workflow

View docs
3

Submit your contribution

Fork the project, create a branch, write your code, and open a pull request for the maintainers to review

Learn the Git workflow
4

Stay involved

Review code, answer community questions, and maintain documentation to become a long-term contributor

Read community articles

Ways to contribute

Code

Fix bugs, add features, optimize performance, and write tests

  • Follow the project coding conventions
  • Write unit tests
  • Update related documentation

Documentation

Write technical docs, user guides, API references, and tutorials

  • Improve the README
  • Add Chinese translations
  • Add code examples

Issue reports

Report bugs so maintainers can find and fix problems faster

  • Describe the symptom clearly
  • Provide reproduction steps
  • Include environment details

Design

Schematic design, PCB layout, enclosure design, and UX improvements

  • Use standard tools
  • Follow the design guidelines
  • Provide complete materials

Translation

Translate docs and UI into more languages to broaden a project's reach

  • Professional translation quality
  • Keep terminology consistent
  • Bidirectional translation support

Education

Write tutorials, record videos, and run workshops to help more people get started

  • Step by step
  • Practice-oriented
  • Continuously updated

Code of conduct

Be respectful

Respect different viewpoints, backgrounds, and experience. Discuss constructively and avoid personal attacks and discriminatory language.

Collaborate

Open source is built on collaboration. Help others, accept feedback, and solve problems together.

Aim for quality

Submit high-quality code and documentation, write tests, and keep contributions reliable and maintainable.

License compliance

Understand and follow each project's license, and make sure your contribution complies with its terms.

Give credit

Thank and recognize the work of others, and acknowledge key contributors in the project.

Help Center
