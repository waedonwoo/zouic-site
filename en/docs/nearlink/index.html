概述

星闪技术（NearLink）是华为公司推出的新一代无线短距通信技术，融合了蓝牙和Wi-Fi的优势，提供更低时延、更高可靠性和更大容量的通信能力。

技术特性

  • 超低时延：端到端时延低至2ms
  • 高可靠性：传输成功率超过99.9%
  • 大容量：支持数百个设备并发连接
  • 低功耗：支持多种功耗模式
  • 高安全性：支持加密通信

支持的开发板

  • NearLink DevKit Pro (Hi3881)
  • NearLink Sensor Node (Hi3882)
  • NearLink Gateway (Hi3883)

环境搭建

硬件要求

  • 支持星闪技术的开发板（Hi3881/Hi3882/Hi3883）
  • USB-C数据线
  • Windows/macOS/Linux主机

快速开始

第一步：设备发现

from app.services.nearlink_sdk import nearlink_sdk

# 开始设备发现
nearlink_sdk.start_discovery(timeout=5)

# 获取发现的设备
devices = nearlink_sdk.get_discovered_devices()
for device in devices:
    print(f"设备: {device.name}, ID: {device.device_id}")

第二步：连接设备

# 连接到指定设备
success = nearlink_sdk.connect('nl_device_001')
if success:
    print("连接成功")
else:
    print("连接失败")

第三步：数据传输

# 发送数据
data = {'temperature': 25.5, 'humidity': 60}
success = nearlink_sdk.send_json(data)

# 读取设备信息
info = nearlink_sdk.read_device_info()
print(f"设备信息: {info}")

API参考

RESTful API端点

端点 方法 描述
/api/nearlink/discover GET 开始设备发现
/api/nearlink/devices GET 获取已发现的设备列表
/api/nearlink/connect POST 连接到指定设备
/api/nearlink/disconnect POST 断开连接
/api/nearlink/send POST 发送数据
/api/nearlink/device_info GET 获取设备信息

SDK方法

方法 参数 返回值
start_discovery(timeout) timeout: int (发现超时时间) None
get_discovered_devices() None List[NearLinkDevice]
connect(device_id) device_id: str (设备ID) bool
disconnect() None None
send_json(data) data: dict (JSON数据) bool
read_device_info() None Dict

通信协议

数据包结构

┌─────────────────────────────────────────────┐
│ 星闪协议数据包结构                           │
├─────────┬─────────┬─────────┬───────────────┤
│ Command │ Flags   │ Source  │ Destination   │
│ (1 byte)│ (1 byte)│ (2 bytes)│ (2 bytes)    │
├─────────┴─────────┴─────────┴───────────────┤
│              Payload (0-244 bytes)          │
└─────────────────────────────────────────────┘

命令类型

命令码 名称 描述
0x01 DISCOVER 设备发现
0x02 CONNECT 连接请求
0x03 DISCONNECT 断开连接
0x04 DATA 数据传输
0x05 ACK 确认响应
0x06 NACK 否定响应
0x07 HEARTBEAT 心跳包

示例代码

完整示例：传感器数据采集

from app.services.nearlink_sdk import nearlink_sdk
import time

def collect_sensor_data():
    # 开始设备发现
    nearlink_sdk.start_discovery(timeout=5)
    
    # 获取传感器设备
    devices = nearlink_sdk.get_discovered_devices()
    sensor_device = None
    
    for device in devices:
        if 'Sensor' in device.name:
            sensor_device = device
            break
    
    if not sensor_device:
        print("未找到传感器设备")
        return
    
    # 连接设备
    success = nearlink_sdk.connect(sensor_device.device_id)
    if not success:
        print("连接失败")
        return
    
    print(f"已连接到 {sensor_device.name}")
    
    # 持续采集数据
    try:
        while True:
            # 发送采集请求
            nearlink_sdk.send_json({'command': 'read_sensors'})
            
            # 读取设备信息
            info = nearlink_sdk.read_device_info()
            print(f"设备信息: {info}")
            
            time.sleep(2)
    except KeyboardInterrupt:
        print("停止采集")
    finally:
        nearlink_sdk.disconnect()

if __name__ == '__main__':
    collect_sensor_data()

Web应用集成示例

// JavaScript示例：使用REST API
async function discoverDevices() {
    const response = await fetch('/api/nearlink/discover');
    const data = await response.json();
    console.log('发现的设备:', data.devices);
    return data.devices;
}

async function connectDevice(deviceId) {
    const response = await fetch('/api/nearlink/connect', {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify({ device_id: deviceId })
    });
    return await response.json();
}

async function sendData(message) {
    const response = await fetch('/api/nearlink/send', {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify({ message })
    });
    return await response.json();
}

// 使用示例
discoverDevices().then(devices => {
    if (devices.length > 0) {
        connectDevice(devices[0].device_id).then(() => {
            sendData('Hello NearLink!');
        });
    }
});
