What is RISC-V?

RISC-V is an open-source reduced instruction set computer (RISC) architecture. It was started at UC Berkeley in 2010 to create a free, open instruction set architecture for academia and industry.

RISC-V advantages

  • Open and free: the ISA is free to use forever, with no licensing fees
  • Modular design: multiple extensions adapt flexibly to different applications
  • Broad adoption: used by more than 1,000 companies worldwide
  • Rich ecosystem: mature toolchains and software support
  • Innovation-driven: an active open-source community keeps pushing it forward

RISC-V application scenarios

Embedded

IoT, sensors, low-power devices

Servers

Data centers, cloud computing, high-performance computing

Consumer electronics

Smartphones, tablets, wearables
