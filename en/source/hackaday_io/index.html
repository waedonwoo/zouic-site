8-bit Workbench ED: hands-on with number systems

Get hands-on with number systems and explore the computer byte. Toggle eight bits and see their decimal, hexadecimal and octal value. Annotations at bit-level break down the displayed value and make comprehension easy. Powered by USB-C or a 9-volt battery. Includes a built-in game: beat the high score by toggling in the correct bits for each number system. A great STEM learning kit, on display at Teardown 2026 in Portland.

Hackaday.io general

ASCII Keyboard Tester Tiny: test vintage keyboards

Evolutionary design of the legendary ASCII Keyboard Tester. It can now eavesdrop on the signals generated by a keyboard and transmitted to the vintage computer, without interfering with its normal operation. It still supports familiar standalone usage, so a (self-made) keyboard can be tested in isolation. All bits are annotated to ease conversion and understanding of hexadecimal and decimal number systems. Use the DIP switch to turn off the 8th bit or activate adapter mode, the latter to use an Apple ][ keyboard with an Apple-1 computer.

IOT ModbusBox

ModbusBox allows the integration of industrial controllers and devices that use Modbus RTU into the IoT world. Configuration goes through an embedded web portal (AP mode for setup, client mode on your local WiFi). It can read data registers from up to 4 Modbus slaves and periodically publish to cloud or local IoT services via MQTT, serialized as JSON for easy parsing.

Hackaday.io general

MCS-85 - Self modifying program

This small and simple project explains how to write self modifying code with an 80C85 microprocessor of the MCS-85 family. The program will only RUN from RAM: we cannot run it from ROM or EPROM since the program dynamically modifies its own CODE while executing. The demonstration shows an array of 8 LEDs with one LED moving left and right.

Micro-8

Micro-8 is an 8-bit computer with a custom OS and a custom C-like programming language called Lofi, along with a suite of examples, tools and utilities to help you create small 2D games and applications that run on real hardware. Based around an ATmega128 8-bit RISC MCU, it features custom FPGA graphics and audio (on top of a genuine YM2612 chip), a fully custom mechanical keyboard and a 220-page full-color printed manual.
