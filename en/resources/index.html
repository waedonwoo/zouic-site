This page groups them by purpose, with one line on what each site does and when to use it. All summaries are written by us so you can decide before clicking.

Kernel, bootloaders and build systems

Kernel / Bootloader / Buildroot / Distro

The mainline toolchain from kernel sources to a root filesystem. When you are building a BSP, trimming a system or chasing a boot failure, these are the primary sources — more reliable than any second-hand tutorial.

Linux kernel.org

www.kernel.org
Official release point for every kernel branch (mainline / stable / longterm), with tarballs, changelogs and git repository links. Before starting a port, confirm here that your target version is still under long-term maintenance.
ReachableLinuxKernel

Linux source cross-reference

elixir.bootlin.com
Search kernel sources by version, symbol or file, with one-click jumps from a function call to its definition. Faster than a local grep for building a call graph while reading a driver.
Script-blockedSource readingDrivers
Bot check in place; opens normally in a browser

U-Boot source downloads

ftp.denx.de
Official DENX release directory, with tar.bz2 archives and checksum files ordered by version. For board ports, follow the version pinned by the SoC vendor's BSP rather than grabbing the newest one.
ReachableBootloaderPorting

Buildroot source releases

buildroot.org
Source archives and changelogs by release year. Use it to produce a cross toolchain and root filesystem; the output is lighter than Yocto and suits small to mid-sized products. Move to Yocto only when you need deeper customisation.
ReachableBuild systemRoot filesystem

Debian project

www.debian.org
Official mirror entry point for stable and testing releases, including arm64 / armhf netinst installers. A common starting point for long-running devices and base images.
ReachableDistribution

Ubuntu project

ubuntu.com
Release pages for LTS and interim versions, with server, desktop and cloud images listed separately. ARM boards such as the Raspberry Pi have dedicated image pages; check the LTS support window when choosing.
ReachableDistribution

GNU project

www.gnu.org
Umbrella entry point for GCC, glibc, binutils, GDB, make and other core tools, indexing their manuals and mailing lists. When toolchain behaviour differs between hosts, the official manuals are the authority.
ReachableToolchain

MicroPython official site

micropython.org
Official firmware downloads and documentation, grouped by chip port, with quickref pages listing the modules available on each board. The Chinese site in the original list is no longer maintained; use the official documentation and docs.micropython.org.
Entry movedMicroPythonFirmware
Original Chinese site micropython.openioe.net no longer resolves

Board vendor documentation hubs

Vendor Docs & Examples

Most Chinese development boards ship their documentation directly from the vendor. Official doc sites carry newer versions than cloud-drive bundles and are more complete than forum posts. Match the BSP version to your exact board model here before you start.

100ask.net download centre

download.100ask.net
Companion resource site from Wei Dongshan's team, archiving sources, toolchains and documents by course and board (i.MX6ULL, STM32MP157, T113 and others). Following a course chapter by chapter is the quickest way to find the right bundle.
Reachablei.MX6ULLSTM32MP1

EmbedFire download centre

doc.embedfire.com
EmbedFire's online documentation, organised by board model with full-text search across tutorials, examples and peripheral manuals. Easier to locate a single chapter's example than downloading one large archive.
ReachableSTM32Linux

ALIENTEK download centre

www.openedv.com
Master directory split into STM32 / i.MX6ULL / FPGA / Linux volumes, with schematics, examples and companion documents for the video courses. Check the board revision before downloading so the material matches your hardware.
ReachableSTM32FPGA

Topeet Electronics (iTOP)

www.topeetboard.com
Beijing Topeet's official site (iTOP series). Product pages give system-on-module specifications, carrier-board interfaces and BSP version notes. Useful for comparing module dimensions and pin definitions across i.MX6 / Exynos / RK platforms.
Reachablei.MX6System-on-module

BearPi example repository

gitee.com
BearPi example code covering LiteOS, OpenHarmony and common peripheral drivers; every directory is a minimal project that runs as-is. A good base for a first bring-up sketch.
ReachableOpenHarmonyLiteOS

LicheePi Zero guide

www.kancloud.cn
Getting-started documentation for the Allwinner V3s LicheePi Zero, with step-by-step notes from flashing and serial login to mainline kernel builds. Good mainline support and low cost make the V3s a common first Linux board.
ReachableAllwinner V3sMainline kernel

Diantang STM32 tutorials

c.51diantang.com
Chinese-language STM32 teaching site focused on peripheral experiments and practical engineering, with downloadable project templates. Handy when moving from the standard peripheral library to HAL and checking a specific peripheral configuration.
ReachableSTM32Peripherals

KST-51 companion site

www.qdkingst.com
Qingdao Jinsite's site and the source of the companion material for the 8051 textbook, offering book examples, board documents and tool downloads.
Reachable8051 MCUCourse material

Chinese communities and forums

Forums & Community

When an example refuses to run, the answer is usually already in one of these forums. Searching the section for your board brand has a far better hit rate than a general web search.

Armfly / HardMan embedded forum

forum.anfulai.cn
Official Armfly forum, with hands-on threads on STM32H7, RTOS, GUI and instrument boards; discussions lean towards code discipline and real engineering. High hit rate for H7 peripheral timing, DMA and cache-coherency issues.
ReachableSTM32H7RTOS
Original domain armbbs.cn now redirects here

EmbedFire forum

www.firebbs.cn
EmbedFire user Q&A, split into board and module sections; typical topics are peripheral init, clock-tree configuration and filesystem mounting. If a bundled example fails after you buy a board, search here by model first.
ReachableSTM32Linux

ALIENTEK forum (OpenEdv)

www.openedv.com
ALIENTEK's official community with complete STM32 / Linux / FPGA sections; posts often include full projects and oscilloscope captures. Corrections to the official documentation frequently appear here first.
ReachableSTM32FPGA

Topeet ARM developer community

bbs.topeetboard.com
Support forum for the Topeet iTOP series, heavy on BSP updates, kernel porting and Android system issues, with replies from the vendor. The main support channel if you build a product on one of their modules.
ReachableARMBSP

ST Chinese community

www.stmcu.org.cn
ST's official Chinese community for STM32 / STM8 selection, firmware libraries and CubeMX questions. This domain has been unstable recently; if it fails, use the Chinese pages on st.com or the English community.
Script-blockedSTM32Official
Checks timed out or redirected unexpectedly; use community.st.com instead

NXP Chinese community

www.nxpic.org.cn
NXP's Chinese technical community, with many porting and production threads on i.MX, LPC and KW families; vendor FAEs take part. Worth searching before starting an i.MX RT or i.MX 8 design.
ReachableNXPi.MX

Xinluheng / XiaoMeiGe FPGA

www.corecourse.cn
FPGA teaching site and forum from XiaoMeiGe (Xinluheng), with complete example sets from Verilog syntax through timing constraints to SDRAM controllers, runnable on their companion boards.
ReachableFPGAVerilog

Tronlong developer community

www.51ele.net
Tronlong user community with many BSP and industrial application threads for TI AM335x / AM57x and Xilinx Zynq platforms. For projects built on their modules, the material here is often more detailed than the official site.
ReachableTIZynq

ChinaUnix

www.chinaunix.net
Long-established Unix / Linux community with deep archives on the kernel, shell, databases and operations. Useful for classic behaviour and historical pitfalls — you can still find original discussions from fifteen years ago.
ReachableLinuxOperations

21ic electronics portal

www.21ic.com
Chinese electronics industry portal combining component selection, market news and an engineer community. Use it for domestic alternative parts, industry updates or circuit-design questions in the forum.
ReachableComponentsIndustry

Chinese tutorial sites and blogs

Tutorials & Blogs

Structured Chinese-language material, best read in chapter order rather than searched piecemeal. In-depth explanations of kernel mechanisms in particular depend on long-form writing like this.

ALIENTEK online courses

www.yuanzige.com
ALIENTEK's teaching site breaks board courses into on-demand chapters covering STM32, Linux and FPGA. Good for working through one subject systematically from the table of contents.
ReachableSTM32Video courses

Zhaixue Buluo embedded tutorials

www.zhaixue.cc
Chinese tutorial site focused on embedded systems and the Linux kernel, with structured series on C, the driver model, concurrency and memory management. Dense prose that works well as a second, close reading.
ReachableLinux kernelC language

MCU tutorial site

www.51hei.com
Teaching and example site centred on 8051, STM32 and AVR, strong on basic peripherals and course projects; the forum holds complete write-ups of student projects. Useful for first lab exercises or coursework references.
Reachable51STM32

TinyLab (TaiXiao Technology)

tinylab.org
Technical blog covering the Linux kernel, real-time behaviour, RISC-V and toolchains, also maintaining open source projects such as Linux Lab. Worth following for mechanism-level analysis in Chinese.
ReachableLinuxRISC-V

Linux Lab development environment

tinylab.org
Container-based, one-command setup for kernel / driver development and QEMU debugging, avoiding manual cross-toolchain configuration. The fastest way to get a kernel lab running with breakpoints.
ReachableEnvironment setupQEMU

Linux kernel walkthrough

www.kerneltravel.net
Chinese site built around kernel source walkthroughs, explaining memory management, scheduling and filesystems module by module with diagrams. Best read chapter by chapter alongside the source.
ReachableKernelSource walkthrough

Wowotech kernel blog

www.wowotech.net
Long-form analysis of Linux kernel subsystems (clocks, power management, USB, display) and Android internals, with annotated source excerpts. Particularly valuable for obscure subsystem implementations.
ReachableKernel subsystemsAndroid

Electronics link directory

www.dianzishijia.com
Directory of electronics sites grouping component vendors, boards, forums and tools by category. Faster than a search engine for getting an overview of a niche area.
ReachableDirectory

codingdict

codingdict.com
A tutorial site in the style of quick-reference programming guides, covering introductory syntax for many languages and frameworks with runnable examples. Fast for the minimal usage of an API; for deeper mechanics, go back to the official docs.
Script-blockedProgramming basics
Site is under maintenance; some pages may be unavailable

Tutorials, open books and documentation

Books & References

Material you can read from cover to cover. The advantage of Chinese open books is the accompanying runnable labs — you can verify what you have read on your own machine straight away.

Pro Git (Chinese edition)

git-scm.com
Complete Chinese translation of the official Git book, from branching models through server setup to internals. The first four chapters cover everyday collaboration; come back for the rebase conflict chapter when you need it.
ReachableGitVersion control

Google style guides (Chinese edition)

zh-google-styleguide.readthedocs.io
Chinese translations of Google's language style guides, including naming, comments and header conventions for C++, Python, Java and Shell. Section numbers can be cited directly when setting team standards.
ReachableCoding standards

C Programming Perspective

github.com
An open Chinese book from TinyLab that traces how a C program becomes a process, layer by layer from compiling and linking through loading to runtime, with gcc / objdump experiments. The first choice for filling in that low-level gap.
Script-blockedC languageCompile and link
Direct GitHub access occasionally times out; read the BookStack mirror instead
Alternative entry: Read online on BookStack

Shell Programming by Example

github.com
A companion hands-on Shell book organised by task (text processing, process control, batch operations), with runnable scripts and explanations in every section. Read it to understand why a construct is written that way, not just to look up a command.
Script-blockedShellScripting
Direct GitHub access occasionally times out; a BookStack mirror is available
Alternative entry: Read online on BookStack

Software Unit Testing: A Primer

www.zlg.cn
Introductory unit-testing material (PDF) from Zhiyuan Electronics on setting up a test framework, writing assertions and measuring coverage in C projects. A reasonable starting point when adding tests to an embedded codebase.
ReachableUnit testingPDF

PyQt5 tutorial

www.pythonguis.com
English-language PyQt5 tutorial that progresses from windows and layouts to signals, slots and packaging, with directly runnable examples. The Chinese tutorial site in the original list is gone, so this maintained source replaces it.
Entry movedPyQt5GUI
Original entry code.py40.com no longer connects
Alternative entry: Another actively maintained tutorial (zetcode)

qter Qt community

www.qter.org
Chinese Qt community with concentrated discussion of QML, embedded Qt, cross-compilation and packaging, plus tutorials and an index of open source projects. Useful for cross-compilation settings on desktop or embedded Qt GUIs.
ReachableQtQML

BookStack open book reader

www.bookstack.cn
Online reader aggregating open technical books, classified by language and domain, readable chapter by chapter without cloning a repository. Convenient for quickly browsing a book's contents and structure.
ReachableOpen booksOnline reading

C++ code example aggregator

www.hotexamples.com
Extracts function call examples from a large number of open source projects and links back to their origin; enter a class or function name to see how others use it. Faster than documentation for building intuition about an unfamiliar library.
Entry movedCode examplesC++
Original cpp.hotexamples.com is offline; the main site still works

Mirrors and everyday utilities

Mirrors & Tooling

A few entry points you cannot avoid when installing systems, capturing packets or connecting a board. Mirrors come first: switching your package source before an install saves a lot of waiting.

Tsinghua open source mirror

mirrors.tuna.tsinghua.edu.cn
One of the most widely used mirrors in China, covering distribution ISOs, apt / yum repositories, PyPI, GitHub Releases and container images. Switch to it first when installing a system or configuring a package manager.
Script-blockedMirrorapt
Returns 403 to scripted requests; opens normally in a browser

USTC mirror

mirrors.ustc.edu.cn
USTC mirror with a sync scope similar to Tsinghua's, and faster updates for some sources (Anaconda, Arch). A good fallback when the Tsinghua mirror has problems.
Script-blockedMirrorFallback mirror
Returns 403 to scripted requests; opens normally in a browser

Wireshark

www.wireshark.org
Official download page for the packet capture and protocol analysis tool, with installers and sources for every platform. Essential when debugging network protocols or tracking down board communication faults.
ReachablePacket captureProtocols

MobaXterm

mobaxterm.mobatek.net
Windows terminal toolkit combining SSH / SFTP, X11 forwarding, serial ports and tabbed sessions. One tool is enough when you need to watch serial logs and transfer files at the same time.
Script-blockedSerial portSSH
Download page occasionally times out during the TLS handshake

Stduino

www.stduino.com
Graphical development environment for 32-bit MCUs with an Arduino-like interface over HAL. Quick results in teaching, but for production work CubeIDE / Keil remain the better choice.
Script-blockedIDETeaching
Site responds slowly and may be briefly unavailable

Alibaba iconfont

www.iconfont.cn
Widely used free icon and icon-font library. Build a project collection, batch-download SVG / PNG and recolour online. The easyicon domain in the original list has expired, so iconfont replaces it.
Entry movedIconsAssets
Original easyicon.net no longer resolves

About this list

  • Reachability reflects checks run on 2026-10-29. Three states are shown: reachable (direct HTTP 200), script-blocked (the site exists but rejects automated requests; a browser works) and entry moved (the original link is dead and has been replaced with a working address).
  • Dead entries are not silently removed: "Digoboy" already redirected to an unrelated login page when we catalogued it, so no link is offered. easyicon, code.py40.com, cpp.hotexamples.com and micropython.openioe.net are offline and have been replaced by iconfont, PythonGUIs / zetcode, the main hotexamples site and the official MicroPython site; each card says so.
  • Where one organisation has several entry points (for example the EmbedFire docs site and its forum, or Tronlong's site and its community), they are listed separately because they serve different purposes.
  • If you would rather not install a toolchain, see the companion browser tools directory: flash firmware, read Flash and open a serial terminal in the browser, plus the upstream open source repositories and licences behind those capabilities.
  • Found a dead link? Report it through the contribution guide and we will verify and update this page.
