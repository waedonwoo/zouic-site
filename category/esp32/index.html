ESP32 开源项目

ESP32 系列（含 S3、C3、C6 等型号）是 Wi-Fi 与 BLE 双模 SoC，开发上有两条主线：ESP-IDF 更贴近底层、能精细控制电源与外设；Arduino 内核上手更快、生态里现成的库更多。选哪条通常取决于项目对功耗和实时性的要求。

收录的条目覆盖传感器网关、电池供电的长期在线设备、音频与语音交互，以及带屏幕的交互终端。看这类项目时，供电设计与休眠策略往往比功能本身更值得参考。

ESP32 iPhone Agent

用一块七美元的 ESP32-S3 让 AI 真正“动手”用一台 iPhone。开发板自己开 Wi-Fi 热点，在 iOS 屏幕镜像列表里以「ESP32 Agent」出现，接收 H.264 码流但不在板上解码，再通过 BLE 转发给同一台 iPhone 上的 App；App 解码画面，把截图交给任意 OpenAI 兼容的视觉模型，由 planner 与 actor 输出点击、滑动、绘制、输入、按键、回主屏等动作。同一块板还是一把标准 USB HID 键鼠，开启系统辅助触控后，相对鼠标指针把“点击”变成轻点、把“拖拽”变成滑动；指针是相对的，App 会在角落归零，精确点击前先晃动指针定位补偿偏移，每一步结束后等待画面稳定再告诉模型有没有变化。整个过程不需要电脑、不需要付费开发者账号（免费 Apple ID 签名需每 7 天重签一次；一键加入热点依赖付费账号的热点配置能力，免费账号下 App 会显示热点密码手动连接）、也不需要越狱。已知限制：镜像源必须是 iPhone，macOS 不支持，BLE 带宽约 300–500 kbps 因而画面约 480×1040、≤5 fps；锁屏会中断镜像，密码输入、Apple Pay 与 DRM 视频不参与镜像；运行期间 Wi-Fi 占用板载热点故不通外网，模型走蜂窝数据；键盘输入仅 ASCII，横屏尚未支持。许可：代码 MIT，但 AirPlay 部分移植自 UxPlay，链接它的固件二进制按 GPL-3.0 分发。（原作：ESP32 iPhone Agent by Henry Yuan，MIT 授权）

Henry Yuan MIT（固件二进制为 GPL-3.0）
