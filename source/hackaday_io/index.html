8-bit Workbench ED: hands-on with number systems

亲手理解数制的 8 位实验台：拨动 8 个比特开关，实时显示对应的十进制、十六进制与八进制值，比特级标注帮助拆解数值构成。USB-C 或 9V 电池供电，内置按位数答题的小游戏。曾在 Teardown 2026 展出，并将登上美国复古计算杂志。适合 STEM 教学。

Hackaday.io general

ASCII Keyboard Tester Tiny: test vintage keyboards

经典 ASCII 键盘测试器的进化版：可在不影响复古电脑正常工作的前提下旁路监听键盘发往主机的信号，也保留独立模式单测（自制）键盘。每位信号都带标注，便于十六进制与十进制换算理解；DIP 开关可关闭第 8 位或进入适配器模式（让 Apple ][ 键盘接 Apple-1 主机）。所有键盘接口引脚均有标注，方便对接 Sol-20 等其他复古电脑的键盘。

Deep Foundation Laser Scanner

面向深基础桩孔检测的激光扫描方案：深孔验收环境恶劣、风险高，作者希望用机器人代替人下井作业。原理是向四周投射红外激光并逐面测距，计划采用 Sharp 测距传感器与步进电机搭建扫描机构。

Digital VU Meter with Analog Physics

带模拟物理感的数字 VU 表：多数数字 VU 表把指针直接设到测量值，观感生硬。该项目为指针加入物理响应特性，让摆动更接近真实模拟表头的动态。

IoT Exploitation Practice

硬件安全实战记录：作者拆解 TP-Link Archer C7 v2（不幸烧毁）后转战 D-Link DIR-601，已找到 UART 引脚并疑似存在 JTAG，计划接 Arduino 跑 JTAGenum 暴力枚举确认。有意不查现成资料，把整个过程当作学习练习，后续持续更新拆解照片。

IOT ModbusBox

把 Modbus RTU 工业设备接入物联网的网关：内置 Web 配置页，AP 模式配网、接入本地 WiFi 后切换为客户端模式。最多轮询 4 台 Modbus 从机的数据寄存器，按周期以 MQTT 协议上报云端或本地 IoT 服务，JSON 序列化便于解析。

MCS-85 - Self modifying program

用 MCS-85 系列的 80C85 处理器演示自修改代码的小型教学项目：程序只能在 RAM 中运行，放进 ROM/EPROM 会因执行中自我改写代码而失败。演示效果是 8 只 LED 中有一只左右来回移动。

Micro-8

8 位自制计算机：搭载自制操作系统与 C 风格编程语言 Lofi，配套示例、工具与实用程序，可在真机上开发小型 2D 游戏与应用。核心为 ATmega128 8 位 RISC 单片机，图形与音频走自制 FPGA 电路并搭载正品 YM2612 音源芯片，配全定制机械键盘与 220 页全彩纸质手册。
