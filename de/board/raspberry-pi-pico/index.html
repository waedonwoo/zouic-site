Schnellantwort

Raspberry Pi Pico is a development board from Raspberry Pi, listed under Allzweck-Boards. It uses the RP2040 on a RP2040 core. It carries 2MB flash, 264KB RAM, 26 GPIO. Official framework support: MicroPython, CircuitPython, Arduino, PlatformIO. Listed price range CNY 20-50, a budget reference - the vendor page sets the real price. Dual-Core Arm Cortex-M0+ mit programmierbarem PIO und einer 10-jährigen Versorgungsverpflichtung, ideal für Bildungs- und DIY-Projekte. ZouIC indexes 2 open source project(s) built on it.
