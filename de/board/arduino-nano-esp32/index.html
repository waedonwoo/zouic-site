Schnellantwort

Arduino Nano ESP32 is a development board from Arduino, listed under Allzweck-Boards. It uses the ESP32-S3 on a Xtensa core. It carries 8MB flash, 512KB RAM, 22 GPIO. Official framework support: Arduino, ESP-IDF. Listed price range CNY 100-200, a budget reference - the vendor page sets the real price. Nano-Board mit ESP32-S3-Kern, ideal für kompakte IoT-Projekte. ZouIC indexes 1 open source project(s) built on it.
