8-bit Workbench ED: hands-on with number systems

Machen Sie sich praktisch mit Zahlensystemen und erkunden Sie das Computerbyte. Wechseln Sie acht Bits und sehen Sie ihren Dezimal-, Hexadezimal- und Oktalwert. Annotationen auf Bitebene unterbrechen den angezeigten Wert und erleichtern das Verständnis. Angetrieben durch USB-C oder eine 9-Volt-Batterie. Enthält ein eingebautes Spiel: Siege die hohe Punktzahl, indem du die richtigen Bits für jedes Zahlensystem wechselst. Ein großartiges STEM-Lernkit, das auf der Teardown 2026 in Portland ausgestellt wird.

ASCII Keyboard Tester Tiny: test vintage keyboards

Evolutionäres Design des legendären ASCII-Tastaturtesters. Es kann nun die von einer Tastatur erzeugten und an den alten Computer übermittelten Signale anhören, ohne den normalen Betrieb zu stören. Es unterstützt immer noch die bekannte Standalone-Nutzung, so dass eine (selbstgefertigte) Tastatur isoliert getestet werden kann. Alle Bits werden annotiert, um die Konvertierung und das Verständnis von Hexadezimal- und Dezimalzahlensystemen zu erleichtern. Verwenden Sie den DIP-Schalter, um das 8. Bit auszuschalten oder den Adapter-Modus zu aktivieren, letzterer, um eine Apple ][ Tastatur mit einem Apple-1-Computer zu verwenden.

Hackaday.io iot

IOT ModbusBox

ModbusBox ermöglicht die Integration von industriellen Controllern und Geräten, die Modbus RTU verwenden, in die IoT-Welt. Die Konfiguration erfolgt über ein eingebettetes Webportal (AP-Modus zur Einrichtung, Clientmodus auf Ihrem lokalen WLAN). Es kann Datenregister von bis zu 4 Modbus-Slaves lesen und regelmäßig über MQTT in Cloud- oder lokale IoT-Dienste veröffentlichen, die als JSON serialisiert sind, um es einfach zu analysieren.

MCS-85 - Self modifying program

Dieses kleine und einfache Projekt erklärt, wie man selbstmodifizierenden Code mit einem 80C85-Mikroprozessor der MCS-85-Familie schreibt. Das Programm wird nur vom RAM ausgeführt: Wir können es nicht von ROM oder EPROM ausführen, da das Programm seinen eigenen CODE während der Ausführung dynamisch modifiziert. Die Demonstration zeigt ein Array von 8 LEDs mit einer LED, die sich links und rechts bewegt.

Hackaday.io general

Micro-8

Micro-8 ist ein 8-Bit-Computer mit einem benutzerdefinierten Betriebssystem und einer benutzerdefinierten C-ähnlichen Programmiersprache namens Lofi, zusammen mit einer Reihe von Beispielen, Tools und Dienstprogrammen, die Ihnen helfen, kleine 2D-Spiele und Anwendungen zu erstellen, die auf realer Hardware laufen. Basierend auf einem ATmega128 8-Bit RISC MCU, verfügt es über benutzerdefinierte FPGA-Grafik und Audio (zusätzlich zu einem echten YM2612-Chip), eine voll benutzerdefinierte mechanische Tastatur und eine 220-seitige vollfarbige gedruckte Bedienungsanleitung.
