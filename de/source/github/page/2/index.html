GitHub raspberry_pi

Rpi3FanHatPlus

Open-Source-Erweiterungsplattform für Raspberry Pi 5 HAT+: Embedded Mikrochip EMC2303 I²C-Lüfter-Controller (Adresse 0 x2E, Alarmanschluss mit GPIO5). Antreibt zwei Standard-4-polige PWM-Lüfter (mit Drehzahlrücklese) und einen einzigen 2-Leiter-12V-Lüfter und führt UART0 (GPIO14/15) und PPS (GPIO18) mit 5V für GNSS-Module, um eine präzise Zeitmessung zu ermöglichen. Inklusive 12V-Eingangs-Selbstwiederherstellungssicherung, HAT+ ID EEPROM (AT24CS64), 4 Schichten 65 x 56,5 mm, auf der PoE Hüte stapelbar. Die Hardwarequelldatei ist eine KiCad 10, CERN-OHL-S v2 Open-Source-Hardware-Lizenz. Derzeit ist es Revision 1, der Autor hat noch keine Probe überprüft.
