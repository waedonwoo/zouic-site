Leitfaden für Gemeinschaftsbeiträge

Schließen Sie sich dem Open-Source-Hardware-Ökosystem an – bauen, teilen und gemeinsam wachsen

Warum beitragen

Lernen und wachsen

Arbeiten Sie an Open-Source-Projekten und tauschen Sie Ideen mit Entwicklern weltweit aus, während Sie Ihr Wissen über Hardwaredesign, Softwareentwicklung und Systemarchitektur vertiefen

Gemeinschaftliche Anerkennung

Ihre Beiträge werden von Entwicklern auf der ganzen Welt gesehen und genutzt, um Ihre persönliche Marke und technischen Einfluss aufzubauen.

Innovationen vorantreiben

Unterstützen Sie, das Board-Ökosystem zu stärken und mehr großartige Hardware-Projekte zum Leben zu erwecken

Karrierewachstum

Open-Source-Beiträge tragen ein echtes Gewicht bei der Stellensuche und zeigen Ihre technischen Fähigkeiten und Teamarbeit

Wie man beiträgt

1

Wählen Sie ein Projekt

Durchsuchen Sie die Open-Source-Projektgalerie nach etwas, das Sie interessiert, und lernen Sie mehr über seine Bedürfnisse und technische Richtung

Projekte durchsuchen
2

Lesen Sie die Docs

Lesen Sie das Projekt README, die Beitragsrichtlinien und die Codierungsstandards, um die Architektur und den Workflow zu verstehen

Dokumentation ansehen
3

Senden Sie Ihren Beitrag

Fork das Projekt, erstellen Sie einen Branch, schreiben Sie Ihren Code und öffnen Sie eine Pull-Anfrage, die die Maintenancer überprüfen können

Lernen Sie den Git-Workflow kennen
4

Bleiben Sie involviert

Überprüfen Sie Code, beantworten Sie Fragen der Community und pflegen Sie Dokumentation, um langfristig Mitwirkender zu werden

Lesen Sie Community-Artikel

Wege zum Beitrag

Code

Fehler beheben, Funktionen hinzufügen, Leistung optimieren und Tests schreiben

  • Folgen Sie den Projektkodierungskonventionen
  • Einheitstests schreiben
  • Aktualisieren der zugehörigen Dokumentation

Dokumentation

Schreiben Sie technische Dokumente, Benutzerhandbücher, API-Referenzen und Tutorials

  • Verbessern Sie das Readme
  • Chinesische Übersetzungen hinzufügen
  • Codebeispiele hinzufügen

Ausgabe von Berichten

Fehler melden, damit Warter Probleme schneller finden und beheben können

  • Beschreiben Sie die Symptome deutlich
  • Bereitstellen von Reproduktionsschritten
  • Umgebungsdetails enthalten

Gestaltung

Schematische Gestaltung, Leiterplattenlayout, Gehäusedesign und UX-Verbesserungen

  • Standardwerkzeuge verwenden
  • Befolgen Sie die Designrichtlinien
  • Komplette Materialien liefern

Übersetzung

Übersetzen Sie Dokumente und Benutzeroberfläche in mehr Sprachen, um die Reichweite eines Projekts zu erweitern

  • Professionelle Übersetzungsqualität
  • Halten Sie die Terminologie konsistent
  • Bidirektionale Übersetzungsunterstützung

Bildung

Tutorials schreiben, Videos aufnehmen und Workshops durchführen, um mehr Menschen zu helfen

  • Schritt für Schritt
  • Praxisorientiert
  • Kontinuierlich aktualisiert

Verhaltenskodex

Seien Sie respektvoll

Respektieren Sie verschiedene Standpunkte, Hintergründe und Erfahrungen. Diskutieren Sie konstruktiv und vermeiden Sie persönliche Angriffe und diskriminierende Sprache.

Zusammenarbeiten

Open Source basiert auf Zusammenarbeit. Helfen Sie anderen, akzeptieren Sie Feedback und lösen Sie Probleme gemeinsam.

Ziel für Qualität

Senden Sie hochwertigen Code und Dokumentation ein, schreiben Sie Tests und halten Sie Beiträge zuverlässig und wartbar.

Einhaltung der Lizenz

Verstehen und befolgen Sie die Lizenz jedes Projekts und stellen Sie sicher, dass Ihr Beitrag den Bedingungen entspricht.

Kredit geben

Danken und anerkennen Sie die Arbeit anderer und würdigen Sie die wichtigsten Mitwirkenden im Projekt.

Hilfe-Center

Willkommen im ZouIC Hilfe-Center. Hier finden Sie ausführliche Anleitungen und Antworten auf häufige Fragen zur Nutzung der Plattform.
