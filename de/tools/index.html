On-site Hardware Calculators: Trace Width, Via Current, Power Budget

Three browser-only calculators: every formula and constant is printed on the page, what you type stays in your browser and never reaches a server. The worked examples come from the same Python reference implementation the page recalculates against.

PCB Trace Width and Current Calculator

Give it the current, allowed temperature rise, copper weight and layer, and it inverts the common IPC-2221 chart fit for the minimum trace width, then adds the resistance, voltage drop and heating of that run. Calculated in the browser; nothing is uploaded.

Open the calculator →

Via Current and Barrel Resistance Calculator

Works out the plated barrel cross-section from drill diameter and plating thickness, then uses the same IPC-2221 fit to estimate how much current one via carries, together with barrel resistance, drop and dissipation. Calculated in the browser; nothing is uploaded.

Open the calculator →

Board Power Budget and Battery Runtime Calculator

List each load with voltage, current and supply path (direct / LDO / DC-DC) to get total input power and current, a margin-inclusive supply rating, and battery runtime converted through energy. Calculated in the browser; nothing is uploaded.

Open the calculator →

How this set of pages works

Browser only: your inputs are used locally, with no request, no database write and no analytics. Closing the page discards them.
Open maths: the formula and every constant are on the page for you to check, and the limits of the fit are stated on the same page rather than buried in a footnote.
One source of truth: the worked examples are generated by our Python reference implementation and compared line by line against the in-browser result; if the two disagree we do not ship it.
Lower-bound estimates with warnings, not a design certificate: every page states at the bottom what the result cannot decide for you.
