Schnellantwort

Langstreckenkommunikation LoRa is an open source project indexed by ZouIC — intermediate-level, written in C++, built on Arduino, released under GPL. Verwendet ein LoRa-Modul zur Ferndatenübertragung. It is linked to ESP32-S3-DevKitC, ESP32-C3-DevKitM, Raspberry Pi Pico.
